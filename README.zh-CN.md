# Model Fit

**Status: Public Preview · v0.2.1-preview**

执行前，根据你当前客户端和账号实际可用的模型与推理档位，提供简短建议。你手动选择并确认；需要时，分段入口会在每个阶段开始前重新评估。

Model Fit 是选档顾问，不是自动切换模型的路由器。

[English](README.md) · [Release 与下载](https://github.com/yuezjo/model-fit/releases/tag/v0.2.1-preview)

## 它做什么

默认从 **`$model-fit-goldilocks`** 开始，附上你的任务。它先核对任务需要的能力，推荐合适且可用的模型与档位，然后暂停，等待执行确认。保持当前配置或只降低当前模型的推理档位，也可以是建议；只有有意义时才提供备选。

最终选择由你决定。你单独确认后，agent 才执行约定任务，并报告实际做过的检查。Model Fit 用指令规定这套流程，不修改客户端设置，也不是系统级执行锁。

## 什么时候值得用

当你有实际可选的模型或档位，希望根据任务的判断难度、风险和可验证性来选择时，可以使用它。较大任务存在明显不同、值得分别评估的阶段时，分段入口也有帮助。

极小、明确的任务可能不值得多一次预判；只有一个固定配置时，没有可切换的省量选项。任务不限于代码，但本包面向 **本地 Codex skill 安装**，不承诺跨平台通用。

## 安装与更新

从 [v0.2.1-preview 预发布页面](https://github.com/yuezjo/model-fit/releases/tag/v0.2.1-preview)选择附件：

- **`model-fit-v0.2.1-preview-goldilocks.zip`**：完整项目，包含文档、安装器、维护源码、工具和测试。
- **`model-fit-v0.2.1-preview-goldilocks-skills.zip`**：四个独立 skill 文件夹及本次发布的许可证，用于手动安装。

无需运行时依赖。解压后，将需要的完整 skill 文件夹复制到 `~/.agents/skills/`。完整包中的文件夹位于 `skills/` 内；轻量包中直接位于压缩包根目录。每个入口可以独立安装，必须保留 `SKILL.md` 旁边的 `agents/`、`references/`、`assets/`。

例如：`~/.agents/skills/model-fit-goldilocks/SKILL.md`。

**完整包**中的可选安装器需要 Python 3.9+，无需额外软件包。在解压后的 `model-fit` 目录运行：

```bash
python3 install.py          # 仅预览，不改文件
python3 install.py --apply  # 安装或更新全部四个入口
```

安装器会把同名旧文件夹备份到 skill 扫描目录之外，保留额外的本地文件，不修改私人校准或当前模型设置。遇到不相关文件夹、Git 工作目录、符号链接或文件与目录冲突时会停止。手动更新前，也应先把旧文件夹备份到扫描目录外。

新入口没有出现时，重启客户端。曾安装旧名版本的用户，请先看 [Goldilocks 更名迁移说明](docs/RENAME-GOLDILOCKS.md)。单入口安装、项目级安装、恢复及移除方法见[安装细节](docs/INSTALL.md)。

## 一次完整使用示例

以下是**格式示例，并非实际运行的测试**。花括号内的模型与档位是占位符，不是真实可用名单。

**1. 调用 skill，附上任务。**

```text
$model-fit-goldilocks 按我提供的报告，整理成指定的对比表。
```

**2. 阅读建议。**

```text
范围：阅读报告，完成指定对比表。
首选：{可用模型} · {可用档位} — 足够处理本任务的判断。
验收：包含指定列；结论能对应到所提供的依据。
重评条件：发现资料缺失，导致任务范围改变。
尚未执行。确认授权本轮完整任务。选择后回复「确认开始」。
```

**3. 在客户端手动选择模型和推理档位。**你可以保持当前配置，也可以不采纳建议；skill 不会替你切换。

**4. 单独发送确认，不再附上 skill 名称。**

```text
确认开始
```

也可使用 `confirm start` 或其他无歧义的执行指令。选择了模型、说「好的」、询问推荐原因或同意保存校准，都不代表执行授权。再次调用 `$model-fit-...` 会重新预判并暂停。

**5. agent 执行约定任务。**在这个例子中，它整理对比表，检查指定列和资料依据，再交付结果并说明未能执行的检查。这里描述的是预期流程，不是实际行为测试的证据。

### 可用配置与私人校准

当前客户端可靠提供可用模型与档位组合时，skill 直接使用；否则，可以提供选择器截图或复制相关选项。确认过的部分名单就足够起步。公开模型页面、本地缓存或其他客户端的配置，不能直接证明这里有权限使用。

经你明确同意且具备文件权限时，可以保存私人校准供四个入口共用。换账号、换客户端或可用选项变化后可能需要刷新；合法的 v0.1 校准仍兼容。不保存凭据或任务内容，也不包含发现接口桥接程序、后台服务或付费探测调用。详见[可用性规则](skills/model-fit-goldilocks/references/availability.md)。

## 四个入口怎么选

默认使用 **`$model-fit-goldilocks`**。四个入口的验收标准保持一致。

| 入口 | 选档方式 | 一次确认授权 |
|---|---|---|
| `$model-fit-goldilocks` | 稳妥选择，有充分依据预期能完成任务的配置 | 本轮完整任务 |
| `$model-fit-cheapskate` | 对低风险、可撤销、容易检查的任务，尝试合理的低消耗配置 | 本轮完整任务 |
| `$model-fit-goldilocks-staged` | 对值得分开的阶段分别稳妥选档 | 仅当前展示的阶段 |
| `$model-fit-cheapskate-staged` | 按阶段评估，在风险允许时积极降档 | 仅当前展示的阶段 |

四个入口可能给出相同建议。普通版不建议分阶段换配置；分段不划算时，分段版也会按单阶段处理。

分段任务中，确认表示接受展示的计划，但**只授权当前阶段**。完成后，agent 给出简短交接和下一条调用，然后停下。再次调用下一阶段并确认后才开始；单独说「继续」不会推进已完成阶段。交接也不代表聊天历史已清空。

## 预览状态

- **有记录的离线检查：**原 Goldilocks 包记录了 Linux/Python 3.13.5 下的 33 项测试通过。本次发布准备在 macOS 27.0（arm64）/Python 3.9.6 下独立运行了构建一致性、包检查和全部 33 项离线测试，无跳过。它们验证文件和安装器行为，不验证真实模型行为。
- **尚未验证：**实际选档质量、跨模型切换后的确认与工具恢复行为、分段接续，以及真实使用消耗。60 个模型行为场景仍是标记为 `not_run` 的定义。此前一次真实使用反馈促成了恢复规则调整，不代表调整已通过行为测试；存在 GitHub Actions 配置也不等于线上 CI 已通过。
- **由你决定：**建议不保证减少 token、额度或费用，不承诺固定节省比例。预判、上下文、检查、交接和返工本身也有消耗。

本次和历史证据、环境及未验证项详见 [VALIDATION.md](VALIDATION.md)。本次只整理发布材料，保留所提供 v0.2.1-preview 的运行指令、安装器行为和模型选择策略。
