# Model Fit

**Status: Public Preview · v0.2.2-preview**

[English manual](README.md)

Model Fit 在执行前，根据你当前实际可用的模型和推理档位，提供简短的选档建议。设置由你手动选择，开始执行前由你确认；对于阶段差异明显的工作，也可以在每个阶段前重新评估。

它是选档顾问，不是自动切换模型的路由器。

## 什么时候值得用

当任务需要较多判断、存在不确定性，或工作量足以让选档产生实际影响时，可以使用 Model Fit。它帮助比较当前设置与其他可用选项，不要求每次都进行冗长分析。

对于简单任务，或已有充分信息的明确后续操作，额外选档的价值可能不大。分段是可选方式，不是默认要求。

## 安装或更新

从 [v0.2.2-preview 预发布页面](https://github.com/yuezjo/model-fit/releases/tag/v0.2.2-preview) 下载一个包：

- **`model-fit-v0.2.2-preview.zip`**：完整项目，包含四个 skills、说明文档、安装器、维护源码、工具及测试。
- **`model-fit-v0.2.2-preview-skills.zip`**：四个独立 skill 文件夹及许可证，适合手动安装。

运行这些 skills 不需要额外依赖。解压后，将需要的完整 skill 文件夹复制到 `~/.agents/skills/`。完整包的入口位于 `skills/` 下，轻量包的入口直接位于压缩包根目录。保留与 `SKILL.md` 同级的 `agents/`、`references/` 和 `assets/`，不要只复制一个文件。四个入口可以独立安装。

例如：`~/.agents/skills/model-fit-goldilocks/SKILL.md`。

**完整包**中的可选安装器需要 Python 3.9+，不需要额外 Python 包。在解压后的项目目录中，先预览变更，再执行安装：

```sh
python3 install.py
python3 install.py --apply
```

更新已有安装使用相同命令。安装器会将被替换的文件备份到 skill 扫描目录之外，保留私人校准，不修改客户端的模型设置。手动更新时，请先备份已有安装并保留私人校准，不要用示例数据覆盖它。

需要具体安装选项时，可参考[安装说明](docs/INSTALL.md)。安装后若看不到入口，请重新加载客户端。

## 一次完整交互

以下是格式示例，不是已执行的模型测试记录。示例任务使用中文，因此交互也使用中文。

**1. 携带任务调用 skill。**

```text
$model-fit-goldilocks 阅读提供的报告，制作所需的对比表。
```

**2. 阅读建议。**

```text
范围：阅读报告并交付所需的对比表。
首选：{实际可用模型} / {实际可用推理档位}，适合任务所需的判断。
验收：包含所需列，结论可追溯到提供的证据。
重新评估条件：缺失证据导致任务范围变化。
尚未开始。本次确认覆盖整个任务。请先选择设置，再单独回复“确认开始”。
```

**3. 在客户端手动选择模型和推理档位。** 可以保留当前设置，也可以选择不同于建议的配置。skill 不会替你切换。

**4. 单独发送确认，不要再次调用 skill。**

```text
确认开始
```

也可使用 `confirm start` 或其他无歧义的执行指令。选择了模型、说“好的”、询问推荐原因，或同意保存校准，都不代表执行授权。再次显式调用 skill 会重新预判并暂停。

**5. 在确认范围内开始执行。** 助手完成任务，并按约定的验收条件检查结果。使用分段入口时，每次确认只授权当前明确命名的阶段，不授权整个项目或下一阶段。

## 四个入口怎么选

默认从 **`model-fit-goldilocks`** 开始。Goldilocks 是其中一个入口的策略名，不是整个套件的名称。

| 入口 | 适用方式 |
| --- | --- |
| `model-fit-goldilocks` | 针对整个任务提供偏稳妥的建议，推荐作为默认入口。 |
| `model-fit-cheapskate` | 针对整个任务提供更注重预算的建议。 |
| `model-fit-goldilocks-staged` | 偏稳妥的分段建议；每个确有必要的阶段分别建议、分别确认。 |
| `model-fit-cheapskate-staged` | 更注重预算的分段建议，遵守相同的逐阶段确认边界。 |

四个入口都只依据已确认的可用选项提供建议，由用户控制设置，并在执行前等待确认。它们不保证选出最便宜或最优的配置。

## 预览状态与反馈

离线检查覆盖生成文件一致性、包完整性和安装器行为。当前自动执行结果见 [GitHub Actions](https://github.com/yuezjo/model-fit/actions)；[验证范围](VALIDATION.md)说明了这些检查能证明什么。

实际选档质量、跨模型接续、工具恢复行为及真实使用消耗仍未验证。已编写的行为场景和个别用户反馈不等于行为测试通过。建议供你决定，不保证减少 token、额度消耗或费用。

此预览版按本地 Codex skills 的使用方式打包，不承诺跨平台通用。

请通过 [Issues](https://github.com/yuezjo/model-fit/issues)反馈版本、客户端及环境、使用的入口、预期结果和实际结果。提交前请删除凭据、私人校准、个人对话及其他敏感信息。
